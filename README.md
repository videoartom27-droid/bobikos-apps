# bobikOS-apps

Маркет приложений для bobikOS mini (ESP32-S2).

## Как добавить новое приложение

1. Создай папку `apps/<имя>/`.
2. Положи туда `app.txt` со скриптом на BobikScript (см. `LANGUAGE.md`
   в прошивке или пример `apps/demo/app.txt`).
3. Добавь запись в `manifest.json`:

```json
{ "name": "<имя>", "path": "apps/<имя>/app.txt" }
```

4. Закоммить и запушь в ветку `main`.
5. На устройстве: меню → **UPDATE** — оно скачает новые/обновлённые
   приложения на SD-карту автоматически.

Имя `"name"` = ровно то, что появится подписью в меню устройства.
